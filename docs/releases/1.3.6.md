# WechatVibe 1.3.6

本次更新以稳定性修复为主：修复聊天助手无法发送、启动失败、读取卡住和画像续跑卡死等问题，助手可以单独选择 API 模型，并改善本地意图识别的几类误判。

### 新增

- **助手独立模型**：右侧助手顶部可选择已保存的 API 档案，与意图分析的模型来源互不影响，主聊天可以继续使用本地 Laya。运行中的助手需先停止再切换；删除该档案或更换其密钥会停止旧请求。
- **真实等待状态**：助手回答前显示实际进行的阶段，例如读取资料、整理上下文和调用模型，回答开始输出后自动收起。意图、画像和三个回复选项在处理中显示加载指示。

### 修复

- **聊天助手**：修复本机无需密钥的模型（Ollama、本机 OpenAI 兼容接口）被误判为缺少密钥，助手引擎初始化失败后继续复用坏连接，以及刷新后恢复成无法停止的“回答中”等问题。助手上下文缓存设置上限，长时间运行不再持续占用内存。远程服务仍需填写密钥。
- **启动与退出**：修复从源码使用 Windows 虚拟环境启动时误报“本地服务未就绪”。启动失败后的清理使用正确端口，不再残留本实例的分析进程；启动失败会显示具体原因代码。
- **消息读取**：修复一条格式异常的消息就能卡住整个界面的问题。微信新建的空消息分片不再导致整个账号读取失败；数据库预写日志变化后不再复用旧快照；没有前台窗口时窗口检测不再出错；切换账号时不再等待模型清理。
- **画像续跑**：修复群成员画像因旧进度记录冲突而反复失败的问题。若未处理完的消息已被删除，会提示重置该画像，不会跳过未读内容。
- **模型接口**：较长的模型 ID 可以正常保存；服务不支持流式请求时自动改用普通响应；过大的错误响应会被拒绝。
- **设置与存储**：浏览器存储写入失败不再打断设置和会话加载。冗余密钥备份损坏时保留原文件并重建，不再导致结果库无法打开。
- **本地意图识别**：文档改期等场景中的“改天”不再被判为拒绝；“你帮我看看”“您帮我查一下”等请对方帮忙的话显示为求助，不再显示为查看；“一般交流”不会因为句中有问号或关键词就显示为意图。旧的本地细标签按新规则自动刷新，API 标签和画像不受影响。

### 已知限制

- 本地 Laya 对反讽和情绪的判断仍然有限，例如反讽的“谢谢你啊”可能仍显示为感谢。需要更准确的结果时可以使用 API 模型。

### 使用与升级

- **标准应用包**：`WechatVibe-1.3.6-windows-x64.zip`，不内置 Laya 模型。解压后运行 `win-unpacked/WechatVibe.exe`，并保留完整目录。
- **源码包**：`WechatVibe-1.3.6-source.zip`，包含本版源码、测试和公开文档。
- **已有模型**：继续使用 `WechatVibe-Laya-model-v1.zip`，已有 Laya 模型无需重新下载。仅使用 API 或聊天助手时无需下载 Laya。
- **升级入口**：在「设置 → 关于 → 当前版本」检查更新。1.3.5 可直接应用内更新到本版，账号数据、分析结果、画像、助手配置及已下载模型都会保留。
- **数据格式**：分析结果的加密格式与 1.3.5 相同，本版没有更改。
- **应用包体积**：移除了此前误带、从未使用的 ffmpeg 程序（约 88 MB），功能不受影响。
